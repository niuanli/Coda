# Coda

**Добавь консоли немного души.** Нативный менеджер звуков Xbox 360 с мастерской для создания образов из двух звуков.

[English](README.md) · [Компоненты и авторство](THIRD_PARTY.md) · [Проверка лицензий](LICENSING.md)

Автор: **Aleksandr Nikitin aka Niuanli**. Текущая версия: **0.4.11**.

## Возможности

- Интерфейс Studio на русском и английском с сохранением языка.
- Библиотека BIN с постраничным списком, обновлением папки и проверкой файлов.
- Резервная копия перед установкой, проверка копии и полная проверка чтением после записи.
- Мастерская: два WAV преобразуются в образ ISD BIN на 45056 байт; исходники не изменяются.
- Предпрослушивание WAV и поддерживаемых BIN через ТВ / HDMI отдельно от воспроизведения звуков чипом.
- Экран об авторе, благодарности и сведения о сторонних компонентах.

## Использование

Скопируйте `Coda.xex` и всю папку `Media` вместе. Нужна Xbox 360 с возможностью запуска homebrew и поддерживаемым звуковым чипом ISD; аппаратным операциям необходим соответствующий доступ к ядру. Сохраняйте резервные копии и не выключайте консоль во время установки.

```text
Coda.xex
Media/
Sounds/     образы BIN для установки
Dumps/      проверенные резервные копии
Imports/    исходные WAV
```

При обновлении сохраняйте `Sounds`, `Dumps`, `Imports` и `coda-language.txt`.

| Экран | Управление |
|---|---|
| Главный | A библиотека; X копия; Y звуки чипа; LB восстановление; Start мастерская; RB язык; L3 About; Back выход |
| Библиотека | D-pad / левый стик выбор; A просмотр; X обновление; Y предпрослушивание; B назад |
| Выбор WAV | A выбрать; Y воспроизвести / остановить; B назад |
| Прослушивание BIN | A включение; X лоток; Y остановка; B назад |
| О программе | X лицензии / описание; B назад |

### Формат мастерской

Вход: **WAV PCM, моно, 8000 Гц, 16 бит**, не более 1 МиБ на файл. Два закодированных звука должны помещаться в 44800 байт — примерно 5,6 секунды с учётом служебных байтов. MP3, пересчёт частоты и редактирование пока не поддерживаются. Предпрослушивание BIN поддерживает ISD PCM с кадрами `0x78`; другие кодировки отклоняются.

### Xenia

В Xenia можно проверить интерфейс, файлы и предпрослушивание через HDMI, но не физический протокол ISD. Для сохранения BIN рядом с XEX включите `allow_game_relative_writes = true` в разделе `[General]` файла `xenia-canary.config.toml` и перезапустите эмулятор. Файлы, добавленные из Windows во время эмуляции, могут потребовать перезапуска приложения из-за кеша файловой системы Xenia.

## Сборка

Нужны Windows PowerShell и отдельно предоставленный Xbox 360 XDK, на использование которого у вас есть право. XDK, дампы прошивок и сторонние звуки в репозиторий не входят.

```powershell
.\build.ps1 -SdkPath 'D:\path\to\XDK'
```

Результаты создаются в соседней папке `Coda-artifacts`, вне репозитория исходников. Путь можно изменить параметром `-ArtifactRoot`. Путь к SDK также можно передать через `CODA_XDK`.

Для генерации редактируемой XUI-сцены и таблиц переводов нужен Python 3:

```powershell
python tools/generate_scene.py
python tools/generate_locale.py
```

Генерация графики требует Pillow: `python tools/studio_assets.py`. PNG-ресурсы и лицензированный шрифт сохранены в исходниках, потому что нужны для сборки. Скомпилированные темы `.xur` создаются при сборке.

## Тесты и архитектура

Запустите `tests\run-all.cmd`. Требуются MSVC C++ Build Tools, Python 3 и компилятор C# из .NET Framework. Тесты используют синтетические звуки и имитацию аппаратуры; сторонние аудиофайлы не нужны.

- `core`: сценарии прошивки и сборки BIN, интерфейсы устройства и хранилищ, формат образа и декодирование предпрослушивания.
- `platform`: адаптеры GPIO и файлов Xbox, фоновое выполнение и XAudio2.
- `ui`: XUI-сцена, отображение каталога и локализация RU/EN.

Сценарии зависят от интерфейсов, а не от Xbox API. Работа с файлами, аудио и отрисовкой разделена. Сборщик сравнивается с C#-эталоном J-Runner. Порядок байтов PCM преобразуется на границе аудиовывода Xbox.
